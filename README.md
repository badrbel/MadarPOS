# 🏪 ShopManager — نظام إدارة المحلات التجارية

> نظام نقطة بيع متكامل (POS) مخصص للمحلات التجارية الجزائرية،  
> يعمل بالكامل بدون إنترنت مع دعم ثنائي اللغة (العربية / الفرنسية).

---

## 📋 وصف البرنامج

**ShopManager** هو برنامج إدارة محلات تجارية احترافي، مُطوَّر بتقنية **.NET / Windows Forms** مع واجهة مستخدم عصرية مبنية على **MaterialSkin2**. يُعدّ الخيار الأمثل لأصحاب المحلات الصغيرة والمتوسطة الذين يحتاجون إلى أداة قوية وسريعة وموثوقة، تعمل **offline بالكامل** مع إمكانية النسخ الاحتياطي السحابي.

---

## ✨ الميزات الرئيسية

### 🛒 نقطة البيع (POS)
- واجهة بيع سريعة مع دعم **الباركود** (قراءة فورية O(1))
- بيع المنتجات **بالوزن** (دعم الميزان الإلكتروني وباركود الميزان)
- دعم **الوحدات الفرعية** (بيع القطعة داخل العبوة)
- دعم **باركودات متعددة** لنفس المنتج
- وصول سريع للمنتجات الأكثر مبيعاً (Quick Access Grid)
- **تعليق الفواتير** وإعادة فتحها لاحقاً (Hold/Resume Invoice)
- طباعة فواتير حرارية (Thermal 80mm) أو A4/A5
- خيار الطباعة الصامتة (Silent Printing)
- دعم طرق الدفع: **نقداً — بطاقة — دَين — مختلط**

### 📦 إدارة المخزون (Inventory + Warehouse)
- إدارة مخزون المحل + **مستودع منفصل**
- تحويل البضاعة بين المحل والمستودع
- تنبيهات تلقائية عند **انخفاض المخزون**
- دعم **تواريخ الانتهاء** للمنتجات
- إدارة الفئات (Categories)

### 🧾 إدارة المشتريات (Purchases)
- تسجيل فواتير الشراء من الموردين
- تتبع الديون للموردين
- تحديث تلقائي لأسعار الشراء والمخزون

### 👥 إدارة العملاء والموردين
- سجل كامل للعملاء والموردين
- تتبع الديون (للعملاء وعلى المحل)
- نظام **نقاط الولاء** (Loyalty Program)
- أرشفة بدلاً من الحذف النهائي (Soft Delete)

### 📊 التقارير والإحصائيات
- تقرير المبيعات اليومية / الشهرية / السنوية
- تقرير الأرباح والخسائر
- تحليل أكثر المنتجات مبيعاً
- تقرير حالة المخزون والتنبيهات
- تقرير الضرائب (TVA) مع تفصيل مجموعات الضريبة
- تقارير جلسات الكاشير

### 💰 نظام الضرائب (TVA)
- دعم معدلات ضريبة متعددة (Inclusive / Exclusive)
- دعم **الطابع الجبائي** (Fiscal Stamp)
- تفصيل TVA في الفاتورة

### 🔐 الأمان وإدارة المستخدمين
- نظام أدوار: **Admin** (مدير كامل الصلاحيات) + **Cashier** (كاشير محدود)
- سجل تدقيق كامل (Audit Log) لكل العمليات
- تتبع جلسات الكاشير مع فتح/إغلاق الصندوق
- قفل الشاشة + تسجيل خروج سريع

### 💾 قاعدة البيانات
- **SQLite** محلية — لا تحتاج إنترنت
- نسخ احتياطية تلقائية
- استرداد تلقائي عند تعطّل قاعدة البيانات
- مزامنة سحابية اختيارية (Cloud Backup)

### 🌐 ثنائية اللغة
- واجهة كاملة بالـ**عربية** (RTL) والـ**فرنسية**
- التبديل بين اللغتين من الإعدادات

## 🔑 نظام الترخيص والتفعيل

يعمل البرنامج بنظام ترخيص ذكي مرتبط بهوية الجهاز (Hardware ID)، ويمر بثلاث مراحل:

### المرحلة 1 — الفترة التجريبية (Trial)
- عند التثبيت الأول، يبدأ البرنامج **فترة تجريبية مجانية مدتها 40 يوماً** تلقائياً.
- يظهر عداد الأيام المتبقية في واجهة البرنامج.
- خلال آخر 3 أيام تظهر رسالة تحذيرية (Trial Warning).

### المرحلة 2 — الكوبونات الترويجية (Coupons)
يمكن تمديد الفترة التجريبية باستخدام كوبونات خاصة **مرة واحدة فقط** لكل جهاز:

> [!IMPORTANT]
> الكوبونات لا تُفعّل البرنامج نهائياً، بل تمدد فقط فترة التجربة.  

| الكوبون | المدة الممنوحة | الاستخدام |
|---------|---------------|-----------|
| `MADAR-4M-PROMO` | **120 يوماً** (4 أشهر) من تاريخ الإدخال | عروض ترويجية |
| `MADAR-1Y-VIP` | **365 يوماً** (سنة كاملة) من تاريخ التثبيت | عملاء VIP |


## 🚀 طريقة الاستخدام

1. شغّل `ShopManager.exe`
2. سيظهر **معالج الإعداد الأولي** (Onboarding Wizard) لتهيئة المتجر.
3. سجّل دخولك بحساب Admin (يُنشأ خلال الإعداد).
4. ابدأ بإضافة منتجاتك من **إدارة المخزون**.
5. استخدم **نقطة البيع** لبدء البيع فوراً.
